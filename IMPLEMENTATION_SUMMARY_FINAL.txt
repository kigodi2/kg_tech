HOW TO USE
================================================================================

IN ADMIN PANEL:
1. Navigate to http://127.0.0.1:8000/admin/system-settings
2. Update any settings
3. Click "Save Settings"
4. Settings persist to database immediately

IN CODE:
use App\Helpers\SystemSettingsHelper;

// Get settings
$chunkSize = SystemSettingsHelper::getImportChunkSize();
$maxZip = SystemSettingsHelper::getMaxZipSize();
$ttl = SystemSettingsHelper::getCacheTtl();
$maintenance = SystemSettingsHelper::isMaintenanceMode();

// Set settings
SystemSettingsHelper::setImportChunkSize(5000);
SystemSettingsHelper::setMaxZipSize(157286400);

// Generic access
$value = SystemSettingsHelper::get('any_key', 'default');
SystemSettingsHelper::set('any_key', 'value', 'string', 'description');
