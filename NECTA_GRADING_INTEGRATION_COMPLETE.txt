================================================================================
WORKFLOW: PROCESSING GRADES FOR AN EXAM YEAR
================================================================================

1. BATCH PROCESS
   POST /api/grading/batch-process
   Input: exam_type_id, year, school_id
   Output: All candidates processed and graded

2. VERIFY RESULTS
   GET /api/grading/school/statistics
   Input: school_id, exam_type_id, year
   Output: Statistics and all results

3. VIEW INDIVIDUAL RESULTS
   GET /api/grading/candidate/{id}/grades
   Output: Detailed report for each candidate

4. STORE GRADES
   POST /api/grading/candidate/{id}/store-grades
   Saves: Grades to final_grades table

5. PUBLISH GRADES
   POST /api/grading/publish
   Input: exam_type_id, year
   Output: Marks is_published = true

6. LOCK GRADES
   POST /api/grading/lock
   Input: exam_type_id, year
   Output: Marks is_locked = true
