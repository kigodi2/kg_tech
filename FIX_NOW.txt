QUICK FIX - 422 ERRORS ON BULK IMPORT
================================================================================

Problem: You're seeing 422 errors when trying to upload ZIP files

Solution: Clear your browser cache

Step 1: CLOSE ALL BROWSER TABS/WINDOWS
- Close Chrome/Firefox/Safari completely
- Make sure no windows are open

Step 2: CLEAR BROWSER CACHE
Windows/Linux:
  1. Open browser
  2. Press Ctrl+Shift+Delete
  3. Click "Cached images and files"
  4. Click "All time" dropdown
  5. Click "Clear data"

Mac:
  1. Open browser
  2. Press Cmd+Shift+Delete (or Cmd+Y then click settings)
  3. Select "Cached images and files"
  4. Click "Clear data"

Step 3: CLOSE AND REOPEN BROWSER
- Close browser completely
- Wait 2 seconds
- Reopen browser

Step 4: NAVIGATE TO PAGE
- Go to http://127.0.0.1:8000/mark-entry/acsee
- Should load fresh with new code

Step 5: TEST UPLOAD
- Select exam year: 2026
- Select school
- Upload ZIP file
- You should see preview (no 422 error)

WHY THIS WORKS
==============
The old JavaScript code had a bug (hardcoded exam_year_id: 1)
The new code has the fix (dynamic exam_year_id extraction)
Browser cache was serving the old buggy code
Clearing cache forces browser to get the new fixed code

WHAT WAS FIXED
==============
✓ Hardcoded exam year ID → Dynamic extraction
✓ Strict MIME validation → Extension-based validation
✓ Poor error handling → Comprehensive error handling
