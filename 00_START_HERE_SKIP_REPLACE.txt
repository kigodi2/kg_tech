SKIP MODE (Default - Safe)
  • Ignores existing candidates
  • Creates only new candidates
  • No changes to existing data
  → Use for: First-time imports, avoiding overwrites

REPLACE MODE (Update)
  • Updates existing candidate details
  • Updates: name, gender, school (only safe fields)
  • Protects: ID, exam type, combination, marks
  → Use for: Fixing candidate info, reassigning schools

Q: Will existing candidates be deleted?
A: No. Skip mode ignores them. Replace only updates safe fields.

Q: Will marks be deleted?
A: No. Never. Replace mode NEVER touches marks or registrations.

Q: What if I don't specify a mode?
A: Defaults to skip (safest behavior).

Q: Can I change exam_type in Replace mode?
A: No. exam_type is immutable to protect exam allocations.
