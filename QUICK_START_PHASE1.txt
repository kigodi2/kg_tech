DATABASE CHANGES
================

New Columns:
- candidates.candidate_type (varchar, default 'SCHOOL')
- candidates.combination_id (bigint FK, nullable)
- candidate_subject_selections.is_principal (boolean, default 0)
- candidate_subject_selections.source (varchar, default 'template')
- candidate_subject_selections.created_by (bigint FK, nullable)

No Deletions, No Truncates, No Breaking Changes
