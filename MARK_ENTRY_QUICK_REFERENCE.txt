TROUBLESHOOTING
================================================================================

Issue: Still getting 422?
Fix:   1. Clear browser cache (Ctrl+Shift+Del)
       2. Check browser DevTools Network → Response headers
       3. Verify _token is in FormData (not headers)
       4. Check storage/logs/laravel.log

Issue: Preview shows no results?
Fix:   1. Verify ZIP file is valid
       2. Check storage/logs/laravel.log for validation errors
       3. Ensure queue worker is running

Issue: Imports are slow?
Fix:   1. Verify queue worker: php artisan queue:work
       2. Check logs for benchmark metrics
       3. May need to increase PHP memory if > 100K rows

Issue: Permission denied on import?
Fix:   1. Verify user has correct role
       2. District officers can only upload to own district
       3. Admins can upload to any district
