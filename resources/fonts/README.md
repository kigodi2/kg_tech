# PDF Font Drop Folder

Place the `Maiandra GD` font file here once, and Outliers PDF exports will auto-embed it.

Accepted names (examples):
- `MaiandraGD.ttf`
- `Maiandra GD.ttf`
- `MaindraGD.ttf`
- `Maindra GD.ttf`

Any `.ttf/.otf/.ttc` file with a filename containing `maiandra` or `maindra` is auto-detected.
