TROUBLESHOOTING
================================================================================

If migration fails:
  1. Check error message
  2. Verify database connection: php artisan db:show
  3. See: PHASE_2_DATABASE_MIGRATION.md

If admin panel won't load:
  1. Clear caches again
  2. Check: storage/logs/laravel.log
  3. See: PHASE_2_DATABASE_MIGRATION.md (Troubleshooting section)

If page shows errors:
  1. Check Laravel logs: tail storage/logs/laravel.log
  2. Clear browser cache (Ctrl+Shift+Delete)
  3. Try incognito window
