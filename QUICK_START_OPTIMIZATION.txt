🔍 HOW IT WORKS (Simple Explanation)
═══════════════════════════════════════════════════════════════════════════════

OLD WAY (Slow):
├─ Read CSV line 1 → Insert to database → 1 query
├─ Read CSV line 2 → Insert to database → 1 query
├─ Read CSV line 3 → Insert to database → 1 query
└─ ... repeat 5000 times = 5000 queries! 😱

NEW WAY (Fast):
├─ Read CSV line 1 → Save to memory
├─ Read CSV line 2 → Save to memory
├─ ... repeat until 500 lines collected
└─ INSERT all 500 at once → 1 query! 🚀
   (repeat ~10 times for 5000 lines)
