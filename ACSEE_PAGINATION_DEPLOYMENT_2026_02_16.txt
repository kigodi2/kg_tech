API ENDPOINT CHANGES
================================================================================

OLD Endpoint Call:
  GET /api/exam-types/acsee/candidates?page=1&page_size=15&search=john

NEW Endpoint Call:
  GET /api/exam-types/acsee/candidates?page=1&per_page=15&q=john&candidate_type=ALL

Query Parameters:
  page              (int)    - Current page number (default: 1)
  per_page          (int)    - Rows per page: 15, 25, 50, 100 (default: 15)
  q                 (string) - Search query for candidate_id or full_name
  candidate_type    (string) - Filter: ALL, SCHOOL, PRIVATE (default: ALL)
  school_id         (int)    - Optional school filter
  district_id       (int)    - Optional district filter
  region_id         (int)    - Optional region filter

Response Format Change:
  OLD: { candidates: [...], pagination: {...} }
  NEW: { data: [...], meta: {...} }

Meta Fields:
  current_page - Current page number
  per_page     - Rows per page
  total        - Total candidate count
  last_page    - Last page number
  from         - First row index on current page
  to           - Last row index on current page

Example Response:
  {
    "data": [
      {
        "id": 123,
        "candidate_id": "A001",
        "full_name": "John Doe",
        "gender": "M",
        "combination": "SC1",
        "school_id": 1,
        "school_name": "High School",
        "allocated_subjects": [...],
        "exam_type": "ACSEE",
        "status": "registered"
      }
    ],
    "meta": {
      "current_page": 1,
      "per_page": 15,
      "total": 6959,
      "last_page": 464,
      "from": 1,
      "to": 15
    }
  }
