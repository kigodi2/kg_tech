📋 MODE DETAILS

SKIP Mode:
  • New records: Imported ✓
  • Existing records: Left unchanged
  • Use case: Appending data, safe default
  • Data loss risk: None

REPLACE Mode:
  • New records: Imported ✓
  • Existing records: Updated with new data
  • Use case: Data updates and corrections
  • Data loss risk: Existing data overwritten

REPLACE ALL Mode:
  • All existing records: DELETED ✗
  • File records: All imported ✓
  • Use case: Complete data refresh
  • Data loss risk: HIGH - all existing data lost

  ✅ Skip: Safe, no data loss
