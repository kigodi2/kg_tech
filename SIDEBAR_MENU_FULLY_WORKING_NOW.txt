Final Issue: Menu clicks not responding
Root Cause: Sidebar outside Alpine.js scope
Solution: Moved x-data to outer wrapper

================================================================================
WHAT WAS WRONG
================================================================================

The sidebar was OUTSIDE the Alpine.js component scope, so menu items couldn't
access the data and methods they needed:

Before (Wrong):
  <div class="w-full flex gap-0">                 <!-- No scope here -->
      <aside>                                       <!-- No scope here -->
          <a @click="importMode = 'schoolBulk'">   <!-- Failed! -->
      <div>
          <div x-data="markEntryManager()">         <!-- Scope only here -->

Problem: 
  • Sidebar clicks: No access to importMode or smoothScroll()
  • Silent failure - no error shown
  • Click handler couldn't execute

================================================================================
HOW IT'S FIXED
================================================================================

Moved x-data to the OUTER wrapper that contains BOTH sidebar and main content:

After (Correct):
  <div class="w-full flex gap-0" x-data="markEntryManager()">  <!-- Scope here -->
      <aside>                                                   <!-- Can access scope -->
          <a @click="importMode = 'schoolBulk'">              <!-- Works! ✅ -->
      <div>
          <div class="space-y-6">                             <!-- Uses parent scope -->

Solution:
  • ALL elements can access importMode and smoothScroll()
  • Single Alpine instance shared across sidebar and content
  • Clean, maintainable architecture

================================================================================
WHY THIS WORKS
================================================================================

Alpine.js Scope Rules:
  1. Child elements inherit parent's x-data scope
  2. Parent data/methods available to all descendants
  3. Single instance = single source of truth

Before Fix:
  Sidebar: No scope → Click handlers fail silently
  Main:    Has scope → Works fine

After Fix:
  Sidebar: Inherits scope → Click handlers work ✅
  Main:    Inherits scope → Still works ✅
