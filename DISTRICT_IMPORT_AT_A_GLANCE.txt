HOW IT WORKS
================================================================================

STEP 1: Select District
  └─ Choose district from searchable dropdown

STEP 2: Upload CSV
  └─ Download template or use your own file
  └─ CSV columns: school_code, candidate_id, full_name, gender, exam_type, exam_year

STEP 3: Preview
  └─ See CSV preview (first 10 rows)
  └─ See registered schools in district
  └─ See schools that will be auto-registered
  └─ Count of new schools to register

STEP 4: Import
  └─ Click "Import Candidates" button
  └─ System creates missing schools
  └─ System creates candidates
  └─ System registers ACSEE candidates
  └─ Returns statistics

RESULT: Statistics displayed
  - Schools registered (new)
  - Schools skipped (already exist)
  - Candidates imported
  - Candidates skipped (duplicates)

================================================================================
KEY FEATURES
================================================================================

✅ AUTO-REGISTER SCHOOLS
   - Schools from CSV not in database are automatically created
   - Assigned to selected district
   - Inherits district's region
   - Ownership set to "GOVERNMENT"

✅ FLEXIBLE CSV FORMAT
   - System recognizes multiple column name variations
   - Case-insensitive header matching
   - Required columns: school_code, candidate_id, full_name, gender
   - Optional: exam_type, exam_year

✅ LIVE PREVIEW
   - CSV parsed in browser before upload
   - Shows first 10 records as sample
   - Identifies which schools will be created
   - Counts displayed in cards

✅ SMART DUPLICATES
   - Existing candidates are skipped (not re-imported)
   - Existing schools are linked
   - Statistics show counts of skipped items

✅ ACSEE INTEGRATION
   - Automatically registers ACSEE candidates
   - Links to specified or active exam year
   - Creates exam registration record

✅ DATA CONSISTENCY
   - Transaction-based operations (atomic)
   - Rollback on any error
   - No partial imports

================================================================================
CSV TEMPLATE FORMAT
================================================================================

Headers (case-insensitive):
  - school_code (or: school, center_no, centre_no)
  - candidate_id (or: index_number, candidate_no)
  - full_name (or: candidate_full_name, name)
  - gender (or: sex)
  - exam_type (or: examination_type, exam)
  - exam_year (or: year, year_label)

Example:
  school_code,candidate_id,full_name,gender,exam_type,exam_year
  S0861,S0861-0001,ABBY JACKSON MARUA,M,ACSEE,2026
  S0861,S0861-0002,ABDUL RAZAQ HAMZA,M,ACSEE,2026
  S0862,S0862-0001,NEW SCHOOL STUDENT,F,ACSEE,2026

S0861, S0862 auto-registered if missing from database

================================================================================
API ENDPOINTS
================================================================================

1. GET /api/districts
   Response: All districts with school count
   Usage: Populate district dropdown

2. GET /api/districts/{districtId}/schools
   Response: Schools in specified district
   Usage: Show registered schools in district

3. POST /api/registration/import-by-district
   Request: file (CSV), district_id (int)
   Response: {
     "schools_registered": 2,
     "schools_skipped": 1,
     "candidates_imported": 45,
     "candidates_skipped": 3,
     "errors": []
   }

================================================================================
DATABASE OPERATIONS
================================================================================

Schools Created:
  - code: From CSV school_code
  - name: "Imported School - [CODE]" (editable later)
  - district_id: Selected district
  - region_id: From district
  - ownership: "GOVERNMENT"
  - is_active: 1

Candidates Created:
  - school_id: From school (existing or created)
  - candidate_id: From CSV
  - full_name: From CSV
  - gender: From CSV (M or F)

Exam Registrations (if ACSEE):
  - candidate_id: The created candidate
  - exam_type_id: ACSEE type
  - exam_year_id: From CSV or active year
  - registration_number: Auto-generated (REG-[uniqid])
