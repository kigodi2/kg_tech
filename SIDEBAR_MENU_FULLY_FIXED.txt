WHAT WAS FIXED (FINAL)
================================================================================

Problem: Clicking "School Bulk ZIP" or "District Bulk ZIP" showed URL hash but
         didn't scroll because sections were hidden by default

Solution: 
  1. Set importMode to show the section
  2. Wait for DOM to update ($nextTick)
  3. Then scroll to the section (smoothScroll)

Result: ✅ ALL 4 MENU ITEMS NOW WORK PERFECTLY

MENU ITEMS CODE
================================================================================

Each item now has 3-step logic:

Step 1: Prevent default anchor behavior
  @click.prevent

Step 2: Set import mode (show/hide sections)
  importMode = 'schoolBulk'

Step 3: Wait for DOM update, then scroll
  $nextTick(() => smoothScroll('#school-bulk'))

Full Example:
  <a @click.prevent="importMode = 'schoolBulk'; $nextTick(() => smoothScroll('#school-bulk'))">
    📦 School Bulk ZIP
  </a>

================================================================================
TECHNICAL IMPLEMENTATION
================================================================================

Alpine.js Integration:
  • Uses $nextTick() to wait for DOM updates
  • Manages importMode for visibility
  • Calls smoothScroll() for navigation

JavaScript Method (markEntryManager):
  smoothScroll(selector) {
      const element = document.querySelector(selector);
      if (element) {
          element.scrollIntoView({
              behavior: 'smooth',
              block: 'start'
          });
      }
  }

Event Handling:
  • @click.prevent - Stop default link behavior
  • importMode = 'x' - Show/hide section
  • $nextTick() - Wait for render
  • smoothScroll() - Animate scroll
