================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "Database migration failed"
→ Check: mysql connection, permissions
→ Solution: Verify DB user has ALTER TABLE permission

Issue: "Smoke tests fail: Column not found"
→ Check: Migrations actually ran
→ Solution: Run php artisan migrate:status

Issue: "PRIVATE candidate cannot allocate subjects"
→ Check: Modal appears? JavaScript errors?
→ Solution: Check browser console, restart PHP-FPM

Issue: "Existing candidates missing subjects"
→ Expected: Pre-deployment data unaffected
→ Solution: No action needed, data integrity is correct

Issue: "API endpoint returns 404"
→ Check: Routes cached?
→ Solution: php artisan route:cache --clear

Issue: "Application won't start after deployment"
→ Check: PHP syntax errors
→ Solution: php artisan tinker (will show errors)
