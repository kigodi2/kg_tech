================================================================================
                        HOW TO USE
================================================================================

FOR EXAM OPERATORS
1. Navigate to: Evaluations → ACSEE → Candidate Performance Anomalies
2. Click "Run Analysis" button
3. Select exam year and type
4. Wait for analysis completion (30 sec - 2 min)
5. Review flagged candidates in dashboard
6. Click "View" to see details
7. Make decision:
   - Mark for Investigation
   - No Action Needed
   - Data Corrected
8. Submit with optional notes
9. Export results to CSV if needed
