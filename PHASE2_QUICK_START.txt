DATABASE VERIFICATION SQL
================================================================================

Verify allocations were saved:
```sql
SELECT 
    c.full_name,
    c.candidate_id,
    s.code,
    s.name,
    css.is_principal,
    css.source,
    u.email as allocated_by,
    css.created_at
FROM candidate_subject_selections css
JOIN candidates c ON css.candidate_id = c.id
JOIN subjects s ON css.subject_id = s.id
LEFT JOIN users u ON css.created_by = u.id
WHERE c.exam_type = 'ACSEE'
ORDER BY c.full_name, s.code;
```

Expected:
- All rows present
- is_principal = 1 or 0 (boolean)
- source = 'manual' or 'template'
- created_by = user ID who allocated
- General Studies (code 111) present for all candidates
- Each candidate has >=4 subjects (GS + 3+ principals)

TROUBLESHOOTING
================================================================================

ISSUE: Modal doesn't open
- Check browser console (F12) for JS errors
- Check Alpine.js is loaded (v3+)
- Click button directly in browser console: 
  document.querySelector('[x-data="acseeManager()"]').__x

ISSUE: Modal opens but dropdowns empty
- Verify exam years exist: SELECT * FROM exam_years;
- Verify combinations exist: SELECT * FROM combinations WHERE exam_type_id = 3;
- Verify subjects exist: SELECT * FROM subjects WHERE exam_type_id = 3;
- Check Network tab (F12) for failed requests

ISSUE: Save button disabled
- Select an exam year first
- Button should enable once year selected

ISSUE: Validation always fails
- Verify General Studies exists: SELECT * FROM subjects WHERE code = '111';
- If missing, create it:
  INSERT INTO subjects (code, name, exam_type_id, created_at, updated_at)
  VALUES ('111', 'GENERAL STUDIES', 3, NOW(), NOW());

ISSUE: API returns 500 error
- Check storage/logs/laravel.log
- Verify authenticated user exists
- Check database connectivity
- Verify exam year exists for the ID provided

ISSUE: Data saved but not showing in list
- Check Database:
  SELECT * FROM candidate_subject_selections 
  WHERE candidate_id = [your_candidate_id];
- Page refresh should show it
- Try clearing browser cache (Ctrl+Shift+Del)
