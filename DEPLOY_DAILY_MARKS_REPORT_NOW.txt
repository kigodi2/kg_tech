API ENDPOINTS
================================================================================

1. GET /api/daily-marks-entry-report
   Query params (optional):
   - exam_year_id=2024
   - region_id=1
   - subject_id=5
   - entry_date=2024-02-12
   Requires: auth + admin middleware

2. GET /api/exam-years
   Returns: Array of exam year objects

3. GET /api/subjects
   Returns: Array of active subject objects

4. GET /api/regions
   Returns: Array of region objects

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "No data available for the selected filters"
→ Check that subject_marks records exist in database

Problem: Dropdowns not loading
→ Check browser console for JavaScript errors
→ Verify ExamYear, Region, Subject records exist

Problem: 401/403 errors
→ Ensure user is logged in
→ Verify user has admin role

Problem: Report shows 0% for all subjects
→ Check created_at timestamps on subject_marks records
→ Verify entry_date filter is not filtering out all data
