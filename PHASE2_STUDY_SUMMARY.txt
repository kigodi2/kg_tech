================================================================================
CSV FORMATS (FINAL SPECIFICATION)
================================================================================

SCHOOL CANDIDATE ALLOCATION CSV:
────────────────────────────────
exam_year,index_number,combination_code,replace_allocations
2026,S0445-0001,PCB,NO
2026,S0445-0002,HGL,NO

- Uses COMBINATION (not subject codes)
- Subjects auto-resolved from combination_subject pivot
- Validation: GS mandatory + ≥3 principals (AcseeAllocationValidator)
- Candidate type must be SCHOOL or index prefix 'S'


PRIVATE CANDIDATE ALLOCATION CSV:
──────────────────────────────────
exam_year,index_number,subject_codes,replace_allocations
2026,P0652-0501,111|112|123|145,NO
2026,P0652-0502,111|001|002|003,NO

- Uses SUBJECT CODES (pipe-separated)
- Must include 111 (General Studies)
- Must include ≥3 principal subjects
- Candidate type must be PRIVATE or index prefix 'P'
- Validation: Same rules as SCHOOL (AcseeAllocationValidator)
