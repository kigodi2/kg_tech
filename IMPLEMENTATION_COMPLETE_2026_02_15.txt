================================================================================
                        API ENDPOINTS
================================================================================

EXISTING (SYNC - for small imports):
  POST   /api/candidates/import/validate
         - Dry-run validation
         - Returns: total_rows, valid_count, invalid_count, errors

  POST   /api/candidates/import/commit
         - Execute import
         - Returns: success, message, imported_count, etc

  GET    /api/candidates/import/template
         - Download CSV template

  POST   /api/candidates/import/download-errors
         - Download error report CSV

NEW (ASYNC - for bulk imports):
  POST   /api/candidates/import/async
         - Dispatch async import job
         - Returns: 202 Accepted, import_id, file_path
