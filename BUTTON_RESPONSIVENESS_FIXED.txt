ISSUE: Button was not responding when clicked
STATUS: ✅ FIXED

================================================================================
WHAT WAS WRONG
================================================================================

The modal had an INLINE STYLE that was preventing Alpine.js from showing it:

    <div x-show="modalOpen || viewModalOpen" 
         style="display: none;">  ← THIS WAS THE PROBLEM

Even though Alpine.js x-show said "show", the inline style said "hide",
and inline styles override x-show directives.

================================================================================
THE FIX
================================================================================

1. REMOVED the conflicting inline style
   
   FROM: style="display: none;"
   TO:   (removed)

2. FIXED the form's HTML structure
   - Corrected nested div tags
   - Removed 4 extra closing </div> tags
   - Proper indentation

3. UPDATED CSS class
   FROM: z-[9999]
   TO:   z-9999

================================================================================
HOW IT WORKS NOW (STEP BY STEP)
================================================================================

1. User clicks "Register Candidate" button
   ↓
2. Alpine.js calls openAddModal() function
   ↓
3. openAddModal() sets: this.modalOpen = true
   ↓
4. x-show="modalOpen || viewModalOpen" sees modalOpen=true
   ↓
5. Alpine.js removes display:none and shows the modal
   ↓
6. Modal appears with smooth x-transition animation
   ↓
7. First Name input is auto-focused (via $nextTick)
   ↓
8. User can fill the form and submit
   ↓
9. saveCandidate() sends data to API
   ↓
10. Success message shown, candidate registered
