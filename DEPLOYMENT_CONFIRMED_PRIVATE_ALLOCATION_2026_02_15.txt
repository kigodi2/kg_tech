FEATURE READY FOR USE
================================================================================

USERS CAN NOW:
  1. Add 'subjects' column to candidate import CSV
  2. Use pipe-delimited subject codes (111|102|103|121)
  3. Import PRIVATE candidates
  4. Automatically get allocations created
  5. View "Allocated Subjects" on /exam-types/acsee

CSV FORMAT:
  candidate_id,full_name,gender,school_code,candidate_type,subjects
  P0001-0001,John,M,SCH001,PRIVATE,111|102|103|121

RESPONSE:
  {
    "imported_count": 1,
    "allocations_created_count": 4,
    "allocation_errors": []
  }

VALIDATION RULES
================================================================================

ENFORCED BY SYSTEM:
  ✓ General Studies (111) mandatory
  ✓ Minimum 3 principal subjects required
  ✓ No duplicate subject IDs
  ✓ All subjects must exist in database

VALID EXAMPLES:
  ✓ 111|102|103|121 (1 GS + 3 principals)
  ✓ 111|102|103|121|122 (1 GS + 4 principals)

INVALID EXAMPLES:
  ✗ 102|103|121 (missing GS)
  ✗ 111|102|103 (only 2 principals)
