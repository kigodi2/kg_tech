HOW TO IMPORT CANDIDATES
================================================================================

STEP 1: Click Tools button (top right, blue button)
STEP 2: Click "Import CSV" 
STEP 3: Select your CSV file
STEP 4: Enter exam year (default: 2026) → Click OK
STEP 5: Select import mode:
        1 = Skip existing (RECOMMENDED)
        2 = Replace existing
        3 = Replace all
        → Click OK
STEP 6: Import completes! 
        → Table refreshes automatically
        → Success message shows count

================================================================================
CSV FORMAT REQUIRED
================================================================================

Column Headers Needed:
  - candidate_id      (e.g., S1378-0501)
  - full_name         (e.g., John Doe)
  - sex               (M or F)
  - school_code       (e.g., 1378)
  - exam_type         (PSLE, CSEE, or ACSEE)
  - combination       (e.g., PCM - ACSEE only)

Example CSV:
  candidate_id,full_name,sex,combination,school_code,exam_type
  S1378-0501,JOHN DOE,M,PCM,1378,ACSEE
  S1378-0502,JANE SMITH,F,CBE,1378,ACSEE

================================================================================
IMPORT MODES
================================================================================

MODE 1: Skip Existing (DEFAULT)
  ✓ Only adds NEW candidates
  ✓ Leaves existing candidates UNCHANGED
  ✓ SAFE - no data loss
  ✓ Recommended for adding new records

MODE 2: Replace Existing  
  ✓ UPDATES existing candidates with new data
  ✓ ADDS new candidates not in system
  ✓ Safe - existing records are updated, not deleted
  ✓ Good for updating information

MODE 3: Replace All
  ⚠ DELETES ALL existing candidates!
  ⚠ Imports fresh data only
  ⚠ CANNOT BE UNDONE
  ⚠ Use only for complete data refreshes

================================================================================
TROUBLESHOOTING
================================================================================

Nothing happens when clicking Import CSV:
  → Hard refresh browser (Ctrl+Shift+R)
  → Clear cache: php artisan view:clear

Prompt doesn't appear:
  → Make sure you selected a file
  → Check browser console (F12) for errors

Import fails / Error message:
  → Check CSV format matches requirements
  → Verify exam year exists (2024, 2025, 2026, etc)
  → Check school codes in CSV match your system
  → See logs: storage/logs/laravel.log

Table doesn't update:
  → Try refresh page (F5)
  → Check if import actually completed
  → Look for success message in top right

================================================================================
TIPS & TRICKS
================================================================================

✓ Use Mode 1 (Skip) for safe imports
  - New candidates added
  - Existing candidates not changed
  - No risk of data loss

✓ Test with small CSV first
  - Import 5-10 records to verify
  - Check if they appear correctly
  - Then import full dataset

✓ Download template to understand format
  - Tools → CSV Template
  - Use as base for your data

✓ Keep backup of original data
  - Export before large imports
  - Tools → Export Excel

✓ Verify school codes
  - Make sure school_code in CSV exists in system
  - Candidates won't import if school doesn't exist
