================================================================================
AUTO-SCHOOL REGISTRATION FOR CANDIDATES IMPORT - IMPLEMENTATION COMPLETE
================================================================================

FEATURE: The original /registration/candidates template now auto-registers 
         missing schools during CSV import, just like the new district template.

================================================================================
WHAT CHANGED
================================================================================

1. Enhanced Import API Endpoint
   Location: routes/api.php, POST /api/candidates/import
   
   When importing candidates:
   - If school code (CSV column 5) not found in database
   - And it's not a numeric ID
   - System automatically creates the school with:
     * Code: From CSV
     * Name: "Imported School - [CODE]"
     * District: Default district (first in system)
     * Region: Default region (first in system)
     * Ownership: "GOVERNMENT"
     * Status: Active

2. Updated UI Messages
   File: resources/views/registration/candidates.blade.php
   
   Changes:
   - Download message mentions auto-registration
   - Import modal shows info banner about auto-registration
   - Users informed schools will be auto-created

================================================================================
HOW IT WORKS
================================================================================

CSV Import Flow:
  Upload CSV
    ↓
  Parse Headers
    ↓
  For Each Row:
    ├─ Extract school_code from column 5
    ├─ Check if school exists
    │   ├─ Yes: Use existing school
    │   └─ No: Auto-create school
    ├─ Create/Update candidate
    ├─ If ACSEE: Register for exam
    └─ Commit transaction
    ↓
  Return Statistics

================================================================================
CSV FORMAT
================================================================================

Required Columns (in order):
  1. candidate_id - Unique identifier (or auto-generated)
  2. full_name - Candidate full name
  3. gender - M or F
  4. combination - Subject combination (optional)
  5. school_code - School code (auto-registered if missing)
  6. exam_type - PSLE, CSEE, or ACSEE (optional)
  7. exam_year - Year label (optional)

Example:
  candidate_id,full_name,gender,combination,school_code,exam_type,exam_year
  S1378-0001,John Doe,M,CBE,S1378,ACSEE,2026
  S1378-0002,Jane Smith,F,HGE,S1378,ACSEE,2026
  S1379-0001,Peter Brown,M,PCB,S1379,ACSEE,2026

Results:
  - S1378 exists → Linked to existing school
  - S1379 not found → Auto-created as "Imported School - S1379"

================================================================================
ACCESSING THE FEATURE
================================================================================

URL: /registration/candidates
Path: Registration > Candidates Management
Button: Tools > Import CSV

Steps:
  1. Click "Tools" button → "Import CSV"
  2. Select exam year
  3. (Optional) Select exam type
  4. Click "Select File"
  5. Choose CSV file
  6. System processes:
     - Creates missing schools
     - Imports candidates
     - Registers ACSEE (if applicable)
  7. View results

================================================================================
WHAT GETS AUTO-REGISTERED
================================================================================

Schools Created:
  - Code: From CSV school_code column
  - Name: "Imported School - [CODE]" (editable later)
  - District: First district in system (default)
  - Region: First region in system (default)
  - Ownership: "GOVERNMENT"
  - Status: Active

You can edit these details later:
  - Go to /registration/schools
  - Find "Imported School -" entries
  - Edit name, district, region, ownership
  - Save changes

================================================================================
BOTH IMPORT METHODS COMPARISON
================================================================================

Original: /registration/candidates
  ✅ Auto-registers missing schools
  ✅ Per-candidate or bulk import
  ✅ Conflict detection/resolution
  ✅ ACSEE auto-registration
  ✅ Flexible CSV format
  ❌ Schools go to default district
  ❌ No pre-import preview

New: /registration/candidates-by-district
  ✅ Auto-registers schools to specific district
  ✅ District filtering and preview
  ✅ Shows registered vs. new schools
  ✅ ACSEE auto-registration
  ✓ Requires pre-selection of district

Choose:
  - Original: When you don't know districts beforehand
  - District: When you want control over school location

================================================================================
WORKFLOW OPTIONS
================================================================================

Option 1: Use Original Template (Simpler)
  1. Prepare CSV with all candidates and school codes
  2. Go to /registration/candidates
  3. Click Tools > Import CSV
  4. Select exam year and upload
  5. System auto-registers schools (default location)
  6. Edit school details later if needed

Option 2: Use District Template (More Control)
  1. Go to /registration/candidates-by-district
  2. Select target district
  3. Prepare CSV with candidates and school codes
  4. Download template or upload your own
  5. Review preview (shows which schools will be created)
  6. Click Import
  7. Schools auto-registered to selected district
  8. Done - schools already in correct location

================================================================================
MANAGING AUTO-CREATED SCHOOLS
================================================================================

After Import:
  1. Go to /registration/schools
  2. Filter by region if needed
  3. Find "Imported School - [CODE]" entries
  4. Click edit (pencil icon)
  5. Change name, district, region, ownership
  6. Save changes

Example:
  "Imported School - S1379" → "NELSON MANDELA SECONDARY SCHOOL"

================================================================================
ERROR HANDLING
================================================================================

Invalid School Codes:
  - Numeric-only (e.g., "1379"): Not auto-created, treated as school ID
  - Empty values: Skipped (row processed without school)
  - Valid codes (e.g., "S1379"): Auto-created

Validation Still Required:
  - CSV file must be valid
  - Exam year must be selected
  - School code column must not be empty
  - Duplicate candidates are skipped

Transaction Safety:
  - Entire import wrapped in database transaction
  - If any critical error: Whole import rolled back
  - No partial/incomplete imports
