WHAT WAS ADDED:
  When users download bulk CSV exports, the ZIP now automatically includes
  a properly formatted manifest.json file.

WHERE THIS WORKS:
  1. Mark Entry → Single School CSV Download
  2. Mark Entry → District Bulk CSV Download
  3. Any bulk CSV export functionality

HOW IT WORKS:
  1. User selects school/year/district
  2. Click "Download CSVs"
  3. ZIP is generated with:
     ✓ manifest.json (included automatically)
     ✓ CSV files for all subjects
     ✓ Subject metadata
     ✓ Candidate counts

MANIFEST.JSON FORMAT:
  {
    "exam_year": "2026",
    "school_code": "KLERUU",
    "school_name": "KLERUU TEACHERS COLLEGE",
    "scope": {
      "type": "school"
    },
    "files": [
      {
        "filename": "111_GENERAL_STUDIES.csv",
        "subject_code": "111",
        "subject_name": "GENERAL STUDIES",
        "checksum": "sha256:...",
        "candidate_count": 45
      }
    ]
  }
