🚀 READY TO USE

API Endpoints Available:

1. GET /api/grading/reference
   → Returns all grade/division boundaries and excluded subjects

2. POST /api/grading/calculate-grade
   → Input: {"marks": 85}
   → Returns: grade, competence, points, color

3. GET /api/grading/candidate/{id}/grades
   → Query: ?exam_type_id=1&year=2024
   → Returns: Complete grading report with colors

4. POST /api/grading/candidate/{id}/store-grades
   → Saves grades to final_grades table

5. GET /api/grading/school/statistics
   → Query: ?school_id=5&exam_type_id=1&year=2024
   → Returns: School grading statistics

6. POST /api/grading/batch-process
   → Batch process all candidates

7. POST /api/grading/publish
   → Publish grades (make visible)

8. POST /api/grading/lock
   → Lock grades (prevent modifications)

📊 GRADING SYSTEM FEATURES

✅ Grade Calculations
   • Marks → Grade conversion (with 0.5 decimal rounding)
   • 79.5-100 = A (Excellent)
   • 69.5-79.49 = B (Very Good)
   • And 5 more grade levels...

✅ GPA Calculations
   • Excludes 2 subjects (General Studies, Basic Applied Math)
   • Range: 1.0 (best) to 7.0 (worst)
   • Average of included subject points

✅ Division Classification
   • Based on total points
   • 5 levels: I, II, III, IV, O
   • With competence descriptions

✅ Color Coding
   • Official NECTA hex colors
   • A = #00AA7A (Dark Green)
   • B/C = #1FEE0B (Lime Green)
   • D = #EF7043 (Orange)
   • E = #DEF043 (Yellow-Green)
   • S = #FF7272 (Light Red)
   • F = #FF272F (Red)

✅ Subject Management
   • Automatic subject exclusion
   • Separate included/excluded reports
   • Proper accounting in all calculations

✅ Data Storage
   • All grades saved to database
   • Full grading breakdown stored as JSON
   • Publishing and locking support

📝 HOW TO USE

Example 1: Get Candidate Grades
──────────────────────────────
GET /api/grading/candidate/1/grades?exam_type_id=1&year=2024

Response:
{
  "candidate_id": 1,
  "candidate_name": "John Doe",
  "total_marks": 490,
  "total_points": 9,
  "gpa": 1.5,
  "overall_grade": "A",
  "division": { "division": "I", "competence": "Excellent" },
  "subject_grades": [
    {
      "subject_name": "ENGLISH",
      "marks_obtained": 85,
      "grade": "A",
      "competence_level": "Grade A (Excellent)",
      "color": "#00AA7A"
    }
  ]
}

Example 2: Batch Process Grades
─────────────────────────────
POST /api/grading/batch-process
Body: {"exam_type_id": 1, "year": 2024, "school_id": 5}

Response: All candidates processed with grades calculated

Example 3: Store Grades to Database
────────────────────────────────────
POST /api/grading/candidate/1/store-grades
Body: {"exam_type_id": 1, "year": 2024}

Response: Grades saved to final_grades table
