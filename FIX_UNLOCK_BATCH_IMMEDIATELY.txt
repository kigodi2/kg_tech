CRITICAL FIX APPLIED: Unlock Batch Modal
================================================================================
Date: February 14, 2026

ISSUE IDENTIFIED:
The unlock batch request was timing out because of a model binding issue.

ROOT CAUSE:
The route parameter was {batch} which required Laravel's implicit model binding.
This binding was either failing to find the model or taking too long.

SOLUTION APPLIED:
Changed route parameter from {batch} to {batchId} (simple integer parameter)
Updated controller to handle the parameter directly

CHANGES MADE:
1. routes/mark-entry.php (Lines 81-82):
   Changed: Route::post('unlock/{batch}', ...)
   To:      Route::post('unlock/{batchId}', ...)
   Also:    Route::post('lock/{batch}', ...)
   To:      Route::post('lock/{batchId}', ...)

2. app/Http/Controllers/MarkEntry/Api/MarkLifecycleApiController.php (Line 357):
   Changed: public function unlockBatchAction(Request $request, $batchId)
   To:      public function unlockBatchAction(Request $request, $batchId = null)
   Added:   Fallback parameter handling

3. BONUS FIX: Fixed duplicate route name error
   web.php: Renamed 'backups.create' to 'backup.manual-create' to avoid conflict
