API ENDPOINTS
================================================================================

DOWNLOAD BULK CSVS:
  GET /mark-entry/acsee/bulk-csv-download?exam_year_id=1&school_id=9
  Returns: ZIP file with CSVs + manifest.json

PREVIEW UPLOADED ZIP:
  POST /api/bulk-import/preview
  Body: FormData with zip_file
  Returns: { success: true, preview: {...} }

START IMPORT:
  POST /api/bulk-import/start
  Body: { school_id: 9, exam_year_id: 1 }
  Returns: { success: true, bulk_import_id: X }

GET PROGRESS:
  GET /api/bulk-import/{id}/progress
  Returns: { progress: {...} }

================================================================================
TROUBLESHOOTING
================================================================================

IF EXPORT FAILS:
  → Check: Is school selected?
  → Check: Are candidates registered for this year?
  → Check: Is exam year NOT locked?
  → Logs: storage/logs/laravel.log

IF PREVIEW FAILS:
  → Check: Is ZIP file valid and complete?
  → Check: File permissions on storage/app/temp
  → Try: Using fresh ZIP from system (not modified locally)
  → Logs: storage/logs/laravel.log

IF IMPORT DOESN'T START:
  → Check: Session is not timing out (2+ hours)
  → Check: All validations pass (year, school exist)
  → Check: Authorization is correct
  → Logs: storage/logs/laravel.log

IF PROGRESS DOESN'T UPDATE:
  → Check: Browser is not caching API responses
  → Try: Hard refresh (Ctrl+F5)
  → Check: API endpoint is returning data
  → Logs: storage/logs/laravel.log
