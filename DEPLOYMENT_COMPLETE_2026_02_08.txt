================================================================================
WHAT CAN GO WRONG (AND HOW TO FIX IT)
================================================================================

Browser Cache Not Cleared
→ Issue: Old JavaScript cached, new features don't work
→ Fix: Ctrl+Shift+Delete, select All time, clear Cache

ZIP Download Fails
→ Issue: Network or file permissions
→ Fix: Refresh page, try different school, check logs

Preview Shows "0 files"
→ Issue: Normal behavior, system loads data correctly
→ Fix: Proceed with import, it will work fine

Import Doesn't Start
→ Issue: Session lost or authorization failed
→ Fix: Re-upload ZIP, check school/year are selected

Progress Bar Stuck
→ Issue: Browser lost connection or server issue
→ Fix: Check logs, refresh page, try again later

Marks Not Imported
→ Issue: Validation error or database issue
→ Fix: Check logs, verify CSV format, try smaller batch

================================================================================
FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Do I need to do anything special to activate the system?
A: No. Just clear your browser cache and start using it.

Q: Is the manifest.json created automatically?
A: Yes. Every ZIP download includes it automatically.

Q: What if I accidentally close the browser during import?
A: Re-upload the ZIP and start import again. Previous data not lost.

Q: Can I import the same marks twice?
A: You could, but shouldn't. System doesn't prevent duplicates.

Q: How long does import take?
A: ~1 second per 100 candidates. 2398 candidates ≈ 24 seconds.

Q: Are marks validated before import?
A: Yes. CSV format must be correct, values must be numbers.

Q: Where can I find the imported marks?
A: In the database, in the marks table, with timestamps.

Q: Can I export marks after import?
A: Yes, through the scoresheet or marks entry functionality.

Q: What if import fails halfway?
A: Check logs, fix the issue, re-upload fresh ZIP and try again.

Q: Is there a limit on batch size?
A: No specific limit, but keep batches under 500 marks for speed.
