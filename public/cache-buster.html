✓ Fix 422 Error - Cache Clear

What's happening: Your browser is using old cached JavaScript code. This page will help you clear it.
Step 1: Clear Browser Cache

Windows / Linux:

  1. Press Ctrl+Shift+Delete
  2. Select "Cached images and files"
  3. Click "All time"
  4. Click "Clear data"

Mac:

  1. Press Cmd+Shift+Delete
  2. Select "Cached images and files"
  3. Click "All time"
  4. Click "Clear data"

⚠️ Then close the browser completely and reopen it!

Step 2: Wait for Cache Clear

After clearing cache, wait 3 seconds and close browser.

Step 3: Reopen Browser
✓ Success! Browser cache cleared. Click the button below to go to the app.
Having trouble? Open your browser's developer tools (F12), go to Application tab, and manually delete all storage for this site.
