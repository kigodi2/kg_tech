## Grade Boundary Reference

### Marks to Grade Conversion
```
90-100  = A (1 point)  - Excellent
80-89   = A (1 point)  - Excellent
70-79   = B (2 points) - Very Good
60-69   = C (3 points) - Good
50-59   = D (4 points) - Average
40-49   = E (5 points) - Satisfactory
35-39   = S (6 points) - Unsatisfactory
0-34    = F (7 points) - Fail
```

### Division Reference Table
```
3-9    = Division I   (Excellent)
10-12  = Division II  (Very Good)
13-17  = Division III (Good)
18-19  = Division IV  (Average)
20-21  = Division O   (Fail)
```

## Calculation Logic Summary

### Step-by-Step Process

1. **For each subject**, calculate:
   - `Grade = Boundary.lookup(marks)`
   - `Points = Points.lookup(grade)`

2. **Separate subjects:**
   - Included subjects: All except "GENERAL STUDIES" and "BASIC APPLIED MATHEMATICS"
   - Excluded subjects: "GENERAL STUDIES" and "BASIC APPLIED MATHEMATICS"

3. **Calculate Total Marks:**
   ```
   Total Marks = Sum(all subject marks)
   Includes: Everything
   ```

4. **Calculate Total Points:**
   ```
   Total Points = Sum(included subject points)
   Excludes: General Studies, Basic Applied Mathematics
   ```

5. **Calculate GPA:**
   ```
   GPA = Total Points / Number of Included Subjects
   Example: 16 points / 6 subjects = 2.67
   ```

6. **Calculate Division:**
   ```
   Look up Total Points in Division Table
   Example: 16 points → Division II
   ```

7. **Calculate Overall Grade:**
   ```
   Overall Grade = Best grade from all subjects
   Example: A (from highest marks)
   ```

## Key Points to Remember

### What is Included in Calculations
✓ All marks contribute to **Total Marks**  
✓ All subjects (except 2) contribute to **Total Points**  
✓ All subjects (except 2) contribute to **GPA**  
✓ All subjects affect **Overall Grade**

### What is Excluded from Calculations
✗ General Studies marks are **excluded from GPA**  
✗ Basic Applied Math marks are **excluded from GPA**  
✗ General Studies points are **excluded from Total Points**  
✗ Basic Applied Math points are **excluded from Total Points**  
✗ BUT both ARE included in **Total Marks**

### Verification Checklist
Before accepting calculated grades, verify:
- [ ] Total Marks includes all subject marks
- [ ] Total Points excludes General Studies and Basic Applied Math
- [ ] GPA calculated using only included subjects
- [ ] Division determined from Total Points
- [ ] Overall Grade is the best grade achieved

## Implementation Notes

When implementing these calculations:

1. **Always use floating-point for:**
   - Marks
   - GPA
   - Division points ranges

2. **Always use integers for:**
   - Grade points (1-7)
   - Point totals
   - Subject counts

3. **Always handle null values:**
   - No marks yet → return null
   - No included subjects → return null
   - Division out of range → return null

4. **Always validate:**
   - Marks between 0-100
   - Grades are A-F
   - Points are 1-7
   - Division is I, II, III, IV, or O

5. **Always document:**
   - Which subjects are excluded
   - Which subjects are included
   - Why calculations differ from total marks
