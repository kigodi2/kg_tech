ISSUE: System stacking/freezing when using "Import (Advanced)" feature

ROOT CAUSE: Modal component used x-teleport="body" which moved it outside
Alpine.js component scope, making all function calls undefined.

FIX: 
  1. Removed x-teleport wrapper from modal

TECHNICAL SUMMARY FOR DEVELOPERS
================================================================================

ISSUE: Alpine.js scope isolation via x-teleport
IMPACT: All function calls in modal returned undefined
SYMPTOMS: System appeared frozen, no API requests made

BEFORE:
  x-data="schoolManager()"
    └─ Modal teleported to <body>
       └─ @click="downloadImportTemplate()" → ERROR (not in scope)

AFTER:
  x-data="schoolManager()"
    └─ Modal stays inline
       └─ @click="downloadImportTemplate()" → OK (in scope)

BENEFIT: Scope-aware function calls work immediately, no hanging
