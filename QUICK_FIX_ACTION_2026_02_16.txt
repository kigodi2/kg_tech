================================================================================
QUICK FIX - Missing exam_year Column Error
Date: 2026-02-16
Status: ✅ FIXED
================================================================================

PROBLEM SOLVED: "Missing required column: exam_year"

The CSV bulk allocation validator was incorrectly requiring exam_year column.
This has been fixed - exam_year is now optional (comes from UI dropdown).

================================================================================
ACTION REQUIRED
================================================================================

1. HARD REFRESH BROWSER
   Press: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)

2. NAVIGATE TO ACSEE MANAGEMENT
   URL: http://127.0.0.1:8001/exam-types/acsee

3. CLICK "Bulk Import CSV" BUTTON

4. FOLLOW THESE STEPS IN MODAL:

   Step 1: Download Template
   - Click "Private Template" button
   - Save the CSV template

   Step 2: Select Import Mode  
   - Choose "Private (Subject Codes)"

   Step 3: Upload CSV File
   - Click "Select CSV File"
   - Upload your CSV (can now OMIT exam_year column!)

   Step 4: Select Exam Year
   - Choose: 2026 (from dropdown)
   - This is the year that will be used

   Step 5: Set Candidate Type Filter
   - Keep: "Private Only" or change as needed

   Step 6: Click "Validate CSV"
   - Should now validate WITHOUT errors!

================================================================================
CSV FORMAT (CORRECT)
================================================================================

Your CSV should look like this (NO exam_year column needed):

index_number,combination_code,subject_codes
P0001,,(111|121|131)
P0002,,(111|122|132)
P0003,,(121|131|141)

OR with exam_year (still works):

index_number,exam_year,combination_code,subject_codes
P0001,2026,(111|121|131)
P0002,2026,(111|122|132)

Both formats work now! System uses dropdown year (step 4).
