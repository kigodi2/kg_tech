────────────────────────────────────────────────────────────────────────────
BROWSER STORAGE
────────────────────────────────────────────────────────────────────────────

Storage Type: localStorage
Key: 'candidatesPageSize'
Value: Integer (10, 25, 50, or 100)
Scope: Per browser instance
Persistence: Survives browser restart

Load Process:
  1. User opens candidates page
  2. init() function runs
  3. Check localStorage for 'candidatesPageSize'
  4. If found: use saved value
  5. If not found: use default (10)
  6. Load candidates with selected page size

Save Process:
  1. User selects new page size from dropdown
  2. changePageSize() called
  3. localStorage.setItem() executed
  4. Page resets to 1
  5. Data reloaded
  6. UI updates
