🎯 THE PROBLEM

When selecting certain districts (IRINGA MC, KILOLO DC, MUFINDI DC, MAFINGA TC),
no candidates displayed, while IRINGA DC worked fine.

ROOT CAUSE: Schools not properly linked to their districts.

═══════════════════════════════════════════════════════════════════════════

✅ THREE SOLUTIONS IMPLEMENTED

1️⃣ UI VALIDATION
   Prevents registering candidates with mismatched school-district

2️⃣ DATA AUDIT TOOL
   Finds and fixes all integrity problems

3️⃣ DEBUG PANEL
   Shows real-time filtering state and statistics

═══════════════════════════════════════════════════════════════════════════

🔧 SOLUTION 1: UI VALIDATION

Location: Candidate Registration Modal
Behavior: Automatically validates school belongs to selected district

When to Use:
  - When registering new candidates
  - When editing existing candidates

What It Does:
  • Checks if selected school is in selected district
  • Shows warning if mismatch detected
  • Validates before save

═══════════════════════════════════════════════════════════════════════════

🔍 SOLUTION 2: DATA AUDIT TOOL

Location: Tools Menu → Data Audit Button

How to Access:
  1. Click "Tools" button (blue button with wrench icon)
  2. Click "Data Audit"
  3. Wait for scan to complete

Audit Report Shows:
  ✓ Total schools: XXX
  ✓ Total candidates: XXX
  ✓ Schools without district: XXX
  ✓ Specific mismatches (first 10 + count)

What to Do if Issues Found:
  1. Read the list of mismatches
  2. Click "Fix All Mismatches" button
  3. System automatically repairs relationships
  4. Data reloads automatically
  5. Candidates should now appear

═══════════════════════════════════════════════════════════════════════════

🐛 SOLUTION 3: DEBUG PANEL

Location: Tools Menu → Debug Panel Button

How to Access:
  1. Click "Tools" button
  2. Click "Debug Panel"
  3. Panel appears in bottom-right corner (black box)

What It Shows:
  Current Selection:
    • Region: [selected region or None]
    • District: [selected district or None]
    • School: [selected school or None]

  Statistics:
    • Total Schools: [all in database]
    • Filtered Schools: [matching current filters]
    • Total Candidates: [all in database]
    • Displayed Candidates: [currently showing on page]
    • Candidates in Filtered Schools: [KEY METRIC]

Key Metric: "Candidates in Filtered Schools"
  
  0 candidates
    → Schools exist but have no candidates registered
    → Nothing broken, just no data
    → Register candidates for those schools
  
  > 0 candidates
    → Candidates exist but aren't displaying
    → Run Data Audit to find/fix issues
  
  Matches displayed count
    → Everything working correctly

═══════════════════════════════════════════════════════════════════════════

🛠️ TROUBLESHOOTING WORKFLOW

Problem: "No candidates showing for IRINGA MC"

Step 1: Open Debug Panel
  → Tools → Debug Panel

Step 2: Select IRINGA MC district
  → Watch statistics update

Step 3: Check "Candidates in Filtered Schools"

IF 0:
  → No candidates registered for IRINGA MC schools
  → Nothing to fix, register candidates first

IF > 0:
  → Candidates exist but not displaying
  → Proceed to Step 4

Step 4: Run Data Audit
  → Tools → Data Audit
  → Wait for scan

Step 5: Fix Issues
  → Click "Fix All Mismatches"
  → System repairs relationships
  → Data reloads

Step 6: Verify
  → Close debug panel
  → Select IRINGA MC again
  → Candidates should now appear

═══════════════════════════════════════════════════════════════════════════

📊 UNDERSTANDING THE AUDIT REPORT

Audit runs database scan and reports:

Total Schools: 150
  → Total number of schools in system

Total Candidates: 4437
  → Total number of candidates in system

Schools Without District: 3
  → Schools not assigned to any district
  → This is the problem!

Mismatches Found:
  S0445 (Kilolo Secondary) - No district assigned
  S0456 (Mufindi High) - No district assigned
  S0467 (Mafinga Town) - No district assigned
  
  → These are the schools causing candidates to not display

═══════════════════════════════════════════════════════════════════════════

💡 HOW FIXING WORKS

When You Click "Fix All Mismatches":

1. System identifies schools without districts
2. For each orphaned school:
   - Finds candidates registered under that school
   - Uses reference data to infer correct district
   - Assigns district to school
   - Records as "fixed"
3. Returns count of fixed items
4. Automatically reloads page
5. Data should now display correctly

═══════════════════════════════════════════════════════════════════════════

⚠️ IMPORTANT NOTES

School-District Relationship:
  Each school MUST have a district assigned
  
  School → District → Region
  
  If any link is missing, candidates for that school won't display

Data Integrity:
  Regular Maintenance:
    • Run audit monthly
    • Fix any issues immediately
    • Keep data clean
  
  Preventive:
    • UI validation prevents new issues
    • Warn on mismatches
    • Always verify before saving

Backup:
  Before running "Fix All Mismatches":
    • Recommended to backup database
    • System is safe, but better cautious
    • Can test in dev first
