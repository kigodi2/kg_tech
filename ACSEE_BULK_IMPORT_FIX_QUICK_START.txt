 WHAT WAS FIXED?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Cypress E2E tests couldn't detect the bulk import modal as visible because Alpine.js
x-show directive was injecting conflicting inline styles that overrode Tailwind classes.

PROBLEM:     Modal showed as display:block instead of display:flex
ROOT CAUSE:  Alpine x-show + x-transition directives conflicted
SOLUTION:    Replaced with pure :style binding for deterministic display control

BEFORE (BROKEN):
───────────────
<div 
  x-show="allocationModalOpen || bulkImportModalOpen" 
  x-cloak 
  class="fixed inset-0 bg-black/50 flex items-center justify-center z-[9999] p-4" 
  @click.self="closeAllocationModal()" 
  x-transition 
  data-testid="bulk-import-modal"
>

AFTER (FIXED):
──────────────
<div 
  x-cloak 
  @click.self="closeAllocationModal()" 
  :style="(allocationModalOpen || bulkImportModalOpen) 
      ? 'display: flex; position: fixed; inset: 0; z-index: 9999;' 
      : 'display: none;'"
  class="bg-black/50 items-center justify-center p-4" 
  data-testid="bulk-import-modal"
>

 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PAGE LOAD
   • x-cloak hides modal: [x-cloak] { display: none !important; }
   • Alpine initializes
   • x-cloak removed from DOM
   • :style binding evaluates: bulkImportModalOpen = false
   • Result: style="display: none;" applied
   ✓ Modal hidden, no flash

2. USER CLICKS "BULK IMPORT CSV" BUTTON
   • @click triggers openBulkImportModal()
   • bulkImportModalOpen = true
   • Alpine detects reactive change
   • :style binding re-evaluates to true branch
   • Result: style="display: flex; position: fixed; inset: 0; z-index: 9999;"
   ✓ Modal visible with flex layout

3. USER CLOSES MODAL
   • Click close button or outside modal
   • closeAllocationModal() called
   • bulkImportModalOpen = false
   • :style binding re-evaluates to false branch
   • Result: style="display: none;" applied
   ✓ Modal hidden, state reset
