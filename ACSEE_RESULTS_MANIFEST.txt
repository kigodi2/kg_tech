ARCHITECTURE
================================================================================

Request Flow:
  Browser → Routes → Middleware → Policy → Controller → Service → Database

Authorization Layers:
  1. Auth middleware (must be logged in)
  2. Policy gate (must have correct role)
  3. Service scope (automatic jurisdiction filter)
  4. Query scope (additional safety)
  5. Export validation (scope verification)

Caching Strategy:
  - Filter lists cached (1 hour TTL)
  - Per user/year/role combination
  - Automatic invalidation on changes

Query Optimization:
  - Eager loading (no N+1)
  - Database indexes
  - Pagination (avoid memory overload)
  - Parameterized queries

Database Design:
  - Existing models leveraged
  - New export_audit_logs table
  - Foreign key constraints
  - Index on frequently queried columns
