================================================================================
                        USAGE INSTRUCTIONS
================================================================================

FOR SMALL IMPORTS (< 500 candidates):
1. Click "Import CSV" button
2. Select file
3. Click "Validate" button
4. Review results
5. Click "Import" button
6. Wait for completion (5-10 seconds)

FOR LARGE IMPORTS (500+ candidates):
1. Click "Import CSV" button
2. Select file
3. Click "Import" button (dispatched to queue)
4. Get immediate 202 response
5. Check logs for completion
6. Candidates appear after background processing

OR USE API DIRECTLY:
curl -X POST http://127.0.0.1:8000/api/candidates/import/async \
  -F "file=@candidates.csv" \
  -F "exam_year=2026" \
  -F "exam_type=ACSEE" \
  -F "mode=skip"
