HOW IT WORKS
================================================================================

User tries to access /admin
        ↓
Filament checks: canAccessPanel('admin')?
        ↓
Model checks:
  1. panel->getId() === 'admin'   ✓
  2. $user->is_active === true    ✓
  3. $user->isAdministrator()     ✓
        ↓
✅ Access granted  OR  ❌ Redirect to login

Access is logged with:
  - User ID
  - Username
  - Role (irms_role)
  - IP address
  - User agent
  - Timestamp

================================================================================
WHAT HAPPENS AT LOGIN
================================================================================

1. User submits credentials at /admin/login
2. Laravel authenticates user
3. Filament calls User::canAccessPanel(Panel $panel)
4. Our code checks:
   - Is panel ID 'admin'? (yes)
   - Is user active? (check is_active column)
   - Is user administrator? (check irms_role column)
5. If all checks pass:
   - User logged in
   - Access logged to admin.log
   - Redirect to /admin dashboard
6. If any check fails:
   - Redirect back to login
   - No access granted
