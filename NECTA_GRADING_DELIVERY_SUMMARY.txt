📋 GRADING SCALES IMPLEMENTED

MARKS TO GRADE:
  0-34   = F (7 points) - Fail
  35-39  = S (6 points) - Unsatisfactory
  40-49  = E (5 points) - Satisfactory
  50-59  = D (4 points) - Average
  60-69  = C (3 points) - Good
  70-79  = B (2 points) - Very Good
  80-100 = A (1 point)  - Excellent

DIVISION CLASSIFICATION:
  3-9   = Division I   (Excellent)
  10-12  = Division II  (Very Good)
  13-17  = Division III (Good)
  18-19  = Division IV  (Average)
  20-21   = Division O   (Fail)

EXCLUDED SUBJECTS:
  • GENERAL STUDIES
  • BASIC APPLIED MATHEMATICS

💻 SERVICE METHODS AVAILABLE

CORE CALCULATION METHODS:
  • calculateGrade(marks)              → Grade letter (A-F)
  • calculateGPA(candidate, ...)       → GPA (1.0-7.0)
  • calculateTotalMarks(candidate, ...)→ Total marks (all subjects)
  • calculateTotalPoints(candidate, .)→ Total points (excluded subs)
  • calculateDivision(totalPoints)     → Division (I, II, III, IV, O)
  • calculateOverallGrade(candidate, .)→ Best grade achieved

REFERENCE METHODS:
  • getGradePoints(grade)              → Points (1-7)
  • getCompetenceLevel(grade)          → Competence level
  • isExcludedSubject(name)            → Boolean
  • getExcludedSubjects()              → Array
  • getGradeBoundaries()               → Array
  • getGradePointsMapping()            → Array
  • getDivisionBoundaries()            → Array

REPORTING METHODS:
  • generateGradingReport(candidate, .)→ Complete report (array)
  • processBatchGrading(examType, year)→ Multiple reports (array)

⚡ QUICK EXAMPLE

    use App\Services\Results\NectaGradingService;
    use App\Models\Candidate;

    // Create service
    $service = new NectaGradingService();

    // Get candidate
    $candidate = Candidate::find(1);

    // Generate full grading report
    $report = $service->generateGradingReport($candidate, 1, 2024);

    // Access results
    echo "Total Marks: " . $report['total_marks'];        // 490
    echo "Total Points: " . $report['total_points'];      // 9
    echo "GPA: " . $report['gpa'];                        // 1.5
    echo "Division: " . $report['division']['division'];  // I
    echo "Grade: " . $report['overall_grade'];            // A
