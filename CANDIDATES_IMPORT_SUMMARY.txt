HOW TO USE (User)
================================================================================

1. Go to Registration → Candidates page
2. Click "Tools" button → "Import CSV"
3. Click "Download Template" and fill in CSV:
   - candidate_id (required): "S1378-0001"
   - full_name (required): "John Doe"
   - gender (required): "M" or "F"
   - school_code (required): "S1378"
   - combination (optional): "Physics,Chemistry,Math"
   - exam_type (optional): "ACSEE"
   - exam_year (optional): "2026"

4. Upload CSV and click "Validate"
5. Review report:
   - See summary (total, valid, errors)
   - See error table (if any)
   - Download error CSV if needed
6. Click "Import X Records" to commit
7. Done! List refreshes automatically

================================================================================
API ENDPOINTS
================================================================================

All endpoints require authentication (CSRF token auto-included).

POST /api/candidates/import/validate
  Input: CSV file, exam_year?, exam_type?
  Output: { success, total_rows, valid_count, invalid_count, errors[], can_import }
  Purpose: Phase 1 - Preview validation results

POST /api/candidates/import/commit
  Input: CSV file, exam_year?, exam_type?, mode?
  Output: { success, imported_count, skipped_count, updated_count, errors[] }
  Purpose: Phase 2 - Write to database

GET /api/candidates/import/template
  Output: CSV file with template headers
  Purpose: Download empty CSV for users to fill

POST /api/candidates/import/download-errors
  Input: { errors[] }
  Output: CSV file with failed rows and error reasons
  Purpose: Export detailed error report

================================================================================
VALIDATION RULES
================================================================================

candidate_id     → Required, unique, max 50 chars
full_name        → Required, max 255 chars
gender           → Required, must be 'M' or 'F'
school_code      → Required, must exist in database
combination      → Required if ACSEE, subjects must exist
exam_type        → Optional (PSLE, CSEE, ACSEE)
exam_year        → Optional, must be 4-digit year if provided

ERROR HANDLING
================================================================================

Type: Missing Required Field
  Message: "[field] is required"
  Example: "candidate_id is required"

Type: Invalid Format
  Message: "[field] must be [format]"
  Example: "gender must be M or F"

Type: Unique Constraint
  Message: "[field] is duplicated within this file"
  Example: "candidate_id is duplicated within this file"

Type: Foreign Key
  Message: "[field] not found: [value]"
  Example: "school_code not found: S1234"

Type: Business Logic
  Message: "[description]"
  Example: "combination has invalid subjects: ABC"

All errors are returned with:
  - row_number (1-based)
  - candidate_id (if available)
  - full_name (if available)
  - error_messages[] (array of all errors for this row)
  - primary_error (first error, for display)
