CANDIDATE SORTING IN RESULTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SORT ORDER (top to bottom):
  1. COMPLETE  (has marks for ALL subjects)
  2. INCOMPLETE (has marks for SOME subjects)
  3. ABSENT     (has marks for ZERO subjects) ← AT BOTTOM

WITHIN EACH GROUP:
  - Sorted by Division: I → II → III → IV → 0
  - Within division: GPA descending (highest first)

EXAMPLE:
  Position 1:   COMPLETE, Div I,   GPA 3.8
  Position 2:   COMPLETE, Div I,   GPA 3.7
  Position 3:   COMPLETE, Div II,  GPA 3.6
  ...
  Position 68:  ABSENT,   Div I,   (AT BOTTOM)
  Position 69:  ABSENT,   Div II,  (AT BOTTOM)
  Position 70:  ABSENT,   Div IV,  (AT BOTTOM)

RESULT:
  ✓ All ABSENT candidates automatically at bottom
  ✓ Easy to identify who didn't take exam
  ✓ Consistent with NECTA standards

KEY FORMULAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Multi-Paper Subjects:
  marks_obtained = average of all papers

Total Marks:
  total_marks = SUM(marks_obtained for all subjects)

Average Per Subject:
  average = total_marks / number_of_subjects

Total Points:
  total_points = SUM(grade_points for all subjects except excluded)
  
  Excluded subjects: GENERAL STUDIES, BASIC APPLIED MATHEMATICS

GPA:
  gpa = total_points / count(valid_subjects)

Division:
  - GPA 3.00-9.00    → Division I
  - GPA 10.00-12.00  → Division II
  - GPA 13.00-17.00  → Division III
  - GPA 18.00-19.00  → Division IV
  - GPA 20.00-21.00  → Division 0 (Fail)
