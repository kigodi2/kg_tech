HOW IT WORKS
================================================================================

MULTI-PAPER SUBJECT (e.g., Chemistry):
  CSV Input:          Paper 1=85, Paper 2=88, Paper 3=92
  System Action:      Calculate average = (85+88+92)/3 = 88.33
  Stored Values:      paper_1=85, paper_2=88, paper_3=92, marks_obtained=88.33
  Grade:              A (based on 88.33)

SINGLE-PAPER SUBJECT (e.g., General Studies):
  CSV Input:          Paper 1=72
  System Action:      No averaging (only 1 paper)
  Stored Values:      paper_1=72, marks_obtained=72
  Grade:              B (based on 72)

================================================================================
FOR OPERATORS
================================================================================

IMPORTING MARKS:
  1. Prepare CSV with: index_number, sex, papers, paper_1, paper_2, paper_3
  2. Upload through admin interface
  3. System automatically:
     - Detects subject type (multi-paper vs single)
     - Averages papers if needed
     - Calculates grades
     - Updates GPA and Division
  4. Done! No manual action needed

VIEWING RESULTS:
  1. Go to school results page
  2. All marks shown with correct averaging
  3. GPA and Division pre-calculated
  4. Everything automatic

CORRECTING MARKS:
  1. Edit marks in system
  2. Run recalculation:
     php artisan marks:recalculate-obtained
     php artisan grades:recalculate --exam-year=1 --exam-type=ACSEE
  3. Results updated

================================================================================
CSV FORMAT
================================================================================

Header:
  index_number,sex,papers,paper_1,paper_2,paper_3

Example (Chemistry - 3 papers):
  S1378-0501,M,3,85,88,92

Example (General Studies - 1 paper):
  S1378-0502,F,1,72,,,

Note: Leave blank for missing papers (e.g., single-paper subject)

================================================================================
DATABASE FIELDS
================================================================================

subject_marks table:
  paper_1:        First paper mark (or only mark)
  paper_2:        Second paper mark (or practical)
  paper_3:        Third paper mark (or project)
  marks_obtained: FINAL MARK (averaged if multi-paper)
  percentage:     Legacy field (for backward compatibility)
  grade:          Calculated grade (A-F)

candidate_exam_registrations table:
  total_marks:    Sum of all subject marks
  total_points:   Sum of grade points
  gpa:            Grade point average
  division:       Division I, II, III, IV, or 0
  grade:          Overall grade

================================================================================
COMMANDS
================================================================================

Recalculate marks (if needed):
  php artisan marks:recalculate-obtained

Recalculate grades (after mark changes):
  php artisan grades:recalculate --exam-year=1 --exam-type=ACSEE

Check migration status:
  php artisan migrate:status

GRADE BOUNDARIES (NECTA)
================================================================================

Mark Range      Grade   Points
79.5 - 100      A       1
69.5 - 79.4     B       2
59.5 - 69.4     C       3
49.5 - 59.4     D       4
40.0 - 49.4     E       5
Below 40        F       7

DIVISION CALCULATION (based on total points):
  Points 3-9      Division I
  Points 10-12    Division II
  Points 13-17    Division III
  Points 18-19    Division IV
  Points 20+      Fail (0)

EXCLUDED SUBJECTS (not counted in GPA):
  - GENERAL STUDIES
  - BASIC APPLIED MATHEMATICS
